## Standing rules
Most rules (no git writes, program file format, uninitialized memory, test-process cleanup, backups / one roadmap item per unattended stretch, man pages, grammar, host consistency, HistoryLog) are spelled out in `CLAUDE.md`; keep following them. Additionally:
- **Keep this file, `docs/` and `docs/roadmap.md` current** when work changes the state; new work goes into `HistoryLog-Claude.md` "Pending" in the same step.
- **No locks on the layer memory** (owner's design, 2026-11-01): the screen thread reads layers and text screens without synchronization; content may be torn, but nothing may be freed / reallocated, indices stay bounded, nothing may be *lost*; shared state is owned by one thread and handed over by atomic words (GCC `__atomic`, no mutex, no pthreads). Rules: `docs/display-engine.md` "Threading".
- **Editing and input are the same in window and console host** (line input, one-line editor, full-screen editor, monitor, break keys, key codes, escape sequences); prefer shared code behind a driver interface.
- **Never run git write commands**; read-only git is fine. `SAVE "name"` writes the ASCII listing by default, `SAVE "name",B` the binary form.

## What exists (index; semantics in `docs/basic-language.md`, `docs/compiler-and-vm.md`)
- **Pipeline:** tokenizer `bastok` (heap strings, identifiers up to 65535 bytes, line numbers 0..999999) -> program store `baspgm` / `baslin` -> compiler `bascomp` (recursive descent -> heap syntax tree) -> code generator `codegen.c` + `cgen*.c` -> stack VM `vm.[ch]` (resumable, big-endian, 32-bit code addresses via the wide instruction form). Variables in `vars.[ch]` (<= 65535 variables, <= 6 dimensions). Remaining fixed limits: `docs/refactoring.md`. ISA spec: `instset.h` (kept current).
- **Extension words:** the one-byte token space is full; new reserved words are `TOK_XFUNC` (254) + id byte (`XF_*`, `xkeywtbl` in `bastok.c`): `SPACE STRING MIN MAX ATAN2 ERROR JOY FRAME LIBRARY USING UI ...`.
- **Language areas** (all documented in `docs/basic-language.md`): control flow (`FOR` incl. `DOWNTO` / `EACH`, `REPEAT`, `WHILE`, `UNTIL/UEND`, `AGAIN`, `EXIT`, `ITERATE`, `ON`), `PROC` / `FUNC` / `CALL` / `LOCAL` (array parameters by reference), `DEF FN`, `DATA` / `READ` / `RESTORE`, error handling (`ON ERROR`, `ERR`, `ERL`, `ERR$`, `ERROR`, `RESUME`), timers (`AFTER` / `EVERY` / `REMAIN`, 1/60 s, four priorities), `STOP` / `CONT` / `TRACE` / `AUTO`, `PEEK` / `POKE` (1 MiB RAM), numeric and string functions, binary-safe strings, number packing (`MKI$`.. big endian), `PRINT USING` / `FORMAT$`, program commands (`LOAD`, `RUN`, `LIST`, `NEW`, `CLEAR`, `DELETE`, `RENUM`, `MERGE`, `CHAIN`, `FILES`, `SAVE`, `BUILD`, `BYE`), `EDIT` (one-line, full-screen) and `MONITOR` (single-step, breakpoints), `ARGC` / `ARG$` / `ENV$`.
- **I/O subsystem** (`iodev.[ch]`, `docs/io-subsystem.md`): drivers `file dir null mem sh res con play tcp stdin stdout stderr config local`; channels, random access records, `KILL` `RENAME` `MKDIR` `CHDIR` `SEEK`, `EXISTS`; policy hook `iodev_allowed()`.
- **Graphics / sound / input** (`docs/graphics-subsystem.md`, `docs/sound.md`, `docs/controller-support.md`): five layers via the `sdlscr_*` API only; ten graphics words, rest sub-keywords through the table in `gfxops.c`; sprites 248..255 reserved (255 = mouse pointer); `DESIGN`, collisions, `GFX RESET`; synthesizer (`synth.[ch]`, `mml.[ch]`) with `SOUND` `PLAY` `SFX` `ENVELOPE`...; `KEY()`, `ON KEY`, `MOUSE`, `ON MOUSE`, `JOY`, `ON JOY`, `FRAME`, `CLIPBOARD$`.
- **Hosts:** `engine1999` (window, SDL2) and `engine1999c` (console: pipes, scripts, screen mode on a terminal, `--screen` / `--line`), both on the screen driver `scrdrv.h` for editors; `BUILD` makes standalone executables with `ld` only (`basbuild.[ch]`; license exception in `LICENSE-EXCEPTION`, drafted by me, not reviewed by a lawyer).
- **Keyboard:** special keys as ANSI sequences, ISO-8859-15 (`keyseq.[ch]`, `sdlkeys.[ch]`); ESC / Ctrl-C / PAUSE break, `BREAK OFF`; `KEY()` is off in the console host (a held-key guess flickers).
- **Font:** `8x12font1.txt` -> `8x12font1.c` via `fontcomp.pl`; glyphs for control codes 0..31 and Latin-9 128..255.

## Lessons / gotchas
- A new object file needs its dependency line in the makefile (stale objects once hid syntax highlighting after `repl_t` grew).
- The makefile's grammar targets must stay behind `all`.
- `GCC` ignores `(void)` casts for `warn_unused_result`; declarations directly after labels fail in clang / old GCC.
- Under Xvfb any frame that changes a layer costs ~40 ms (software rendering): games run slowly there; scale key timings.
- GFX angle arguments (`GFX CIRCLE`, `GFX RADIUS`) stay in degrees, independent of `DEG` / `RAD` / `GRAD`.
- Design decisions I took are marked "revisit if unwanted" in `docs/basic-language.md` and the matching log entries; revisit them when the owner objects.
