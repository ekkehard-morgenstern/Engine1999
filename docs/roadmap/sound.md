## 2b. Sound

`SOUND`, `PLAY`, `WAVE`, `TEMPO`, `SOUND OFF/SYNC` and `PLAYING()` work (`docs/sound.md`; `synth`, `mml`, `sdlaudio`; tested by `synthtest1`, `vmtest1`, `repltest1`, `asmtest1`).

- [x] Sound effects: `PITCH`/`VOLUME`, glide, `ENVELOPE`, `VIBRATO`/`TREMOLO`, stored `SFX` (done, `docs/sound.md`)
- [ ] Sound effects, more: a pitch envelope, a pulse width for the square wave, a filter for the noise, `SFX` with parameters, `EVERY` timers can now drive `PITCH`/`VOLUME` (try it in the engine demo)
- [ ] Instruments / FM synthesis (operators, envelopes, `INSTRUMENT`), band-limited square/triangle, stereo, a voice allocator — **instruments, subtractive first with 16 presets, are roadmap item 81 (planned 2026-11-08)**
- [ ] Sample-accurate event times (now ≈1 ms), mixing events into the audio callback
- [x] **Check that sound effects do not get lost** *(ticked 2026-11-10: the owner has played all games for days and the problem has not come back)* *(partly addressed 2026-11-07: 16 channels, 1..8 music and 9..16 effects, so effects no longer compete with the music and the march for channels; to check again by playing: hypothesis (2) the mixer's division by the summed gains remains)* (owner, 2026-11-07, minor: while playing `orchard2` effects are occasionally drowned out or do not play). Hypotheses, none checked: (1) `SFX` without a channel takes the highest free channel and, when none is free, channel 8 (`vm_sfx_play()`), where the effect waits behind what the channel has queued (it starts late or after the situation is over); (2) the mixer divides the sum by the summed gains when that is above 1 (`synth_render()`), so a loud effect gets quieter while many channels sound; (3) only 8 channels for music (2 voices), march, UFO and effects. Tool: `ENGINE1999_SOUNDLOG` (`docs/sound.md`; the `pk` values show what was rendered), the capture scripts method of 2026-11-07 (`SDL_AUDIODRIVER=disk`). Possible remedies: reserve channels for effects, let an effect steal the quietest / oldest channel, a limiter instead of the division.
- [x] **Owner to check the other games for sound changes after the `SFX` state restore** *(ticked 2026-11-10: the owner played all games for days, no issues)* (2026-11-07; `climb`, `river`, `madrun`, `rustinpeace`, `glyphminer`, their second editions): an effect now gives the channel back as the program set it (`vm_t.chanstate`); report anything that sounds different.
- [ ] `PLAY`: no chords inside a string (use one string per voice), no `N` (note number) or `X` (run a string variable) commands, no repeat; `PLAY` doesn't wait (a program that ends while music is queued leaves it playing until `SOUND OFF`: decided)
- [ ] Sound output channels other than the BASIC channels (`PRINT #n`) are not involved; no `SOUND` queue inspection beyond `PLAYING()`

- [x] **Numeric functions and operators** (done, 2026-10-31, found while writing `demos/orchard.bas`): `INT FIX ABS SGN SQR SIN COS TAN ATN EXP LOG RND PI`, `RANDOMIZE`, `MOD` and `\`. Not done: `ASN`/`ACS` (arc sine, cosine), hyperbolic functions, `LOG10`/`LOG2`, `CINT`/`CDBL`, `ROUND(x,n)`, `MIN`/`MAX`, `ATAN2(y,x)`, bit helpers; `DEF FN` can build most of them.
- [x] Keyboard for games: **`KEY("name")` is done** (2026-11-01, `docs/basic-language.md` "KEY": the real key state in the window; in the console host it is a run-time error: the held-key guess flickered, the code is kept switched off; **reviewed by the owner 2026-11-01 and left as it is**, see the priority table). `INKEY$` / `GET` get the cursor keys as escape sequences already. The demos `orchard`, `orchard2` and `climb` use it (2026-11-01). Not done: key-up *events* (`ON KEY`), joystick and mouse (section 10).
